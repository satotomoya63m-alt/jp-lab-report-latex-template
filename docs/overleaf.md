# Overleafで使う方法

このページでは、`jp-lab-report-latex-template` を Overleaf で使う方法を説明します。

## 1. リポジトリをZIPでダウンロードする

GitHubのリポジトリページで、緑色の `Code` ボタンを押します。

その後、`Download ZIP` を選択して、このリポジトリをZIPファイルとしてダウンロードします。

## 2. Overleafで新規プロジェクトを作成する

Overleafにログインし、以下の手順でプロジェクトを作成します。

1. `New Project` を押す
2. `Upload Project` を選ぶ
3. ダウンロードしたZIPファイルをアップロードする
